前端没有的功能不要扩展。工作范围限定为：**前端已有界面，但服务端有问题**的功能，
对这部分做修改和完善。

**Why:** 2026-09-01 我提议做报表（按流水类型/科目/部门的账期报表与导出），
用户明确否掉并划定了范围。界面是既定的，服务端要做的是让这些界面真正可用，
而不是长出新页面。

**How to apply:** 拿到"接下来做什么"这类开放问题时，从既有页面出发排查
——某个页面的数据对不对、写操作是否真的落库、报错是否说得清、
权限是否与业务规则一致——而不是提议新功能。已经这样修掉的例子：
流水列表字段错位、借贷页销账没调接口、资产分类被 id 硬编码锁死、
股东统计口径过期、归账不校验币种。
